# ETF Modular Homes — project workspace

This repository is used by Fibo Agency to plan and review a modular-homes website and product configurator.

## Current stage

- Discovery and interactive prototype (non-production).
- New client clarification received and analysed on 2026-11-02; [see scope update](docs/scope-update-2026-11-02.md).
- No production code or customer data has been deployed.
- Main branch is reserved for approved work; development occurs in feature branches with pull requests.

## Target MVP (to be confirmed)

- Six modular-house series with an initial target of eighteen model/size entries; the final matrix needs approval.
- House size, finish and equipment options (including model-dependent add-ons), with a live estimated price persistently displayed at the bottom of the configuration view.
- Quote-request workflow; administration of models, option availability and prices.
- Five locales: LV, EN, LT, ET, RU.
- Responsive, premium visual design.
- No online checkout or automatic invoices.

All of the above remain scope candidates until formally approved. The client reference website is a benchmark, not a complete feature specification.

No client contact details, private correspondence, original product catalogue, or commercial terms are stored here.
