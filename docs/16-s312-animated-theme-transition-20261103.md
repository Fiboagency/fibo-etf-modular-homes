# ETF / ROVELLC S312 — восстановление анимации переключения темы

Дата: 2026-11-03. Статус: реализация в отдельной ветке.

## Почему понадобилось исправление

После редизайна S312 и последующего возвращения иконок солнца/луны пропала **анимация смены темы всего сайта**. У кнопок сохранилось переключение состояний, но вся палитра менялась мгновенно. На старом прототипе присутствовали анимированные состояния управляющих элементов и смены фотографий; при упрощении S312 этот аспект был потерян.

## Реализация
- Независимое управление темой сайта в шапке и изображениями дома AA (день) / BB (ночь) внутри сцены сохранено.
- При нажатии на солнце или луну применяется анимированное круговое раскрытие новой палитры **от активированной кнопки**, 680 мс. Используется View Transitions API, где доступен.
- Для браузеров без View Transitions предусмотрен CSS-переход фона, текста и панелей (580 мс).
- При `prefers-reduced-motion: reduce` темы переключаются сразу, без анимированного эффекта.
- Тема сохраняется локально, как и раньше. Цена и настройки S312 не меняются при смене темы.
- Новые изображения AA/BB не изменены.

## Проверка
- GitHub branch HTML preview, экран 390 × 844: смена light→dark вызывает реально работающую CSS-анимацию `::view-transition-new(root)` продолжительностью **680 мс** (проверено через браузерный Animation API).
- Смена dark→light также имеет 680 мс; фон и элементы меняют тему без смены изображения.
- Переключение AA/BB по прежнему независимо; выбранный язык, фотография и опции сохраняются при перезагрузке.
- При эмуляции `prefers-reduced-motion: reduce` нет классов или ViewTransition-анимаций.
- Проверен desktop 1440px и mobile 390px, нет горизонтального переполнения. Точная длительность анимации измерена в Chromium; iOS Safari ещё требует устройства для окончательного QA.
- Актуальный CSS `theme.css?v=3`, анимация реализована в `prototype/theme.css` и обработчиках `prototype/index.html`.
