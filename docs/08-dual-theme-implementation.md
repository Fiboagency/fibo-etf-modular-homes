# ETF — два визуальных варианта в одном конфигураторе

Дата: 2026-11-01  
Статус: `FIBO OWNER REVIEW / DRAFT`. Оригинальный, ранее выбранный дизайн Architectural Atelier сохранён. По новому прямому поручению владельца добавлен второй полнофункциональный стиль Nightfall Residence и переключатель вариантов в правой части шапки.

## Обзор реализации

- Одна HTML-страница `prototype/index.html`, одна логика опций, одни изображения, одна формула стоимости.
- Два ссылочных режима: `?variant=1` (Architectural Atelier, светлый) и `?variant=2` (Nightfall Residence, тёмный).
- Шапка: две ссылки-кнопки **«Вариант 1»** и **«Вариант 2»**; у выбранной `aria-current="page"`.
- Переключение на текущей странице через `history.pushState` без обновления и потери выбранных опций. История браузера через `popstate` поддерживается. При отключённом JS ссылки остаются обычными навигационными URL, но конфигуратор как таковой требует JS.
- Прямая загрузка `?variant=2` показывает ночное оформление и первоначально выбирает натуральный фасад/ночной кадр; переход с уже выбранной конфигурацией **не** изменяет её.
- Реальные изображения дома в ночном заголовке из файла `B.webp`, для конфигуратора обычная логика A/B/J/K; E/F/G/H; C/D.
- В тёмном варианте меняется **художественная композиция**, а не только фон: крупный uppercase grotesk + мягкий контрастный serif, ночная фотография, бронзовый акцент и чёрная архитектурная панель, другая стилистика карточек, CTA и сметы.

## Принципы фирменного стиля B — Nightfall Residence

- Фон: #171B19. Панели: #242A27 и #1E2420.
- Светлый текст: #F1ECE3; подзаголовки и метаданные #D2D0C4.
- Акцент: #BD9C70 (бронзовый/песочно-золотой, без градиентной мишуры).
- Смысл: «архитектура света» и приватная резиденция. Не представлять это как стандарт SIA ETF: пока концепция Fibo Agency.
- Desktop hero: 45% заголовок, 55% ночное изображение. Mobile: крупный текст сверху, ночной кадр снизу. Интерактивный конфигуратор остаётся единым функциональным блоком.
- Документированный визуальный референс Nightfall был подготовлен в `prototype/design-review.html` до этого изменения.

## Ограничения

- Модели 60/80/100 м², опции, цены — условные. Backend, admin, email и клиентская локализация отсутствуют.
- Для ванной используются только две существующие комбинации, не произвольное смешивание поверхностей.
- Исходники фото предоставлены владельцем. Права для коммерческой клиентской публикации **не подтверждены**.
- Проверка full WCAG и пяти локализаций не проведена.

## Приёмка переключателя

1. `?variant=1` загружает светлую палитру, активен Вариант 1.
2. `?variant=2` загружает тёмную палитру с ночной фотографией, активен Вариант 2.
3. Изменить размер дома, фасад, пол и ванную, нажать на второй вариант → цена и опции не меняются.
4. Нажать на первый вариант → те же параметры и сумма остаются.
5. Кнопка назад/вперёд браузера меняет тему, не сбрасывая конфигурацию.
6. Обе версии показывают действующие пересчёты, формы и ограничение количества окон.
7. Desktop 1440×960 и mobile 390×844: видимые кадры и отсутствие горизонтальной прокрутки, проверить реальную страницу после live deploy.
